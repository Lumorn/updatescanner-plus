# Security Policy

## Sicherheitslücken melden

Bitte melde Sicherheitsprobleme **vertraulich**, wenn möglich über GitHub
Security Advisories. Falls das nicht möglich ist, nutze ein GitHub Issue mit
klarer Kennzeichnung „security“.

## Erwartete Infos

* Firefox-Version und Betriebssystem
* Schritte zur Reproduktion
* Relevante Logs/Konsole (falls vorhanden)

## Hinweise

* Es werden keine Secrets ins Repository committed.
